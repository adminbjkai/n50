AI Model Usage & Enrichment Mechanics

The run_next_set_v11.py script utilizes generative AI model enrichment to classify, filter, and score candidate self-hosted apps. This phase is triggered dynamically when the --enrich CLI flag is provided.

Claude Haiku 4.5 Anthropic
claude-haiku-4-5

Primary Model. Called directly via urllib with native HTTP requests. Delivers high accuracy utilizing structured output constraints (JSON schema formatting).

Nvidia Nemotron 3 OpenRouter
nvidia/nemotron-3-ultra-550b-a55b:free

Fallback Model. Utilized automatically if Anthropic API keys are not detected, but OpenRouter keys are present. Classifies candidates using a system command prompt.

Enrichment Process & Scoring Effects

Key Metric / Action Description & Rules Scoring / System Impact
Self-Hostable Verification LLM inspects metadata to verify if the repository is a deployable app/service rather than a library or CLI utility. If classified as non-self-hostable, a heavy penalty of -15.0 points is applied, filtering it out.
Category Fitting Assigns repositories to a strict list of allowed categories. Fits to standard options without hallucinating new names. Maintains balanced diversity across published category distributions.
Novelty Assessment LLM grades repository novelty from 1 (generic clone) to 5 (highly novel/rare utility). Adds positive or negative adjustments (calculated as (novelty - 3) * novelty_weight).
Interest Hook Draft Generates a succinct, feature-focused user-value hook of 15 words or less (no marketing filler). Published directly onto the Notion set page metadata.
Smart Bypass Optimization

To save API call limits and ensure optimal performance, any repository that is already cataloged in the curated awesome-selfhosted-data index AND passes Docker signature verification is bypassed completely, skipping LLM enrichment under the source label bypass.

Dependency Analysis: Plumbing Architecture

The script run_next_set.py is not just a reference snapshot. It is imported directly inside run_next_set_v11.py as v1 and acts as a core dependencies and utility package for v11.

  • Constants & Paths (v1.TRACKER, v1.MASTER_CSV, v1.AUDIT_DIR) Inherits exact paths to the JSON state tracker, master CSV files, and temp folder structures.
  • Notion Request Plumbing (v1.load_notion_key, v1.notion_request, v1.append_blocks, v1.rt) Reuses HTTP communication functions, rich text construct payloads, and credentials resolution handlers.
  • Reconciliation & Syncing (v1.reconcile_with_notion, v1.write_tracker) Imports the sync logic that queries Notion for live pages to rebuild and dedup local logs.
  • Canonical Verification (v1.canonical_repo) Uses the v1 engine to resolve GitHub redirects, query repository stats, and eliminate dead/forked links.

Runner Execution Pipeline

The runner operates in a sequential, multi-step pipeline built to run quickly while respecting API limit controls.

1

State Synchronization

Runs a reconciliation pass against Notion live blocks to retrieve all published repository URLs. Ensures no duplicates ever cross sets and resolves page title overlaps.

2

Bench Seed & Bounded Search

Loads previously vetted candidates from a bench cache file (bench_v11.json) to reduce network requests. Performs rotating REST sweeps for quality and fresh categories, exiting early once quotas are met (capped at 60 searches).

3

Heuristic Filtering & Scoring

Discards non-app structures (e.g. cheatsheets, books, tutorials). Applies a gentle "fresh gem" gate for young/low-star targets, and calculates multi-factor popularity/activity scores.

4

GraphQL Live Confirmation

Checks the status of the top 130 shortlisted candidates in batches of 35 using GitHub's GraphQL API. Looks up files in the repository tree to check for Docker configuration signals (e.g. docker-compose.yml).

5

AI Enrichment

If enrichment is active, passes ambiguous finalists to Claude Haiku or Nemotron. Discards non-viable apps and applies novelty adjustments.

6

Diversity Balancing & Quotas

Executes a category round-robin selection. If the selection contains fewer fresh gems than the configured --fresh-quota, it swaps out lowest-scoring popular projects for fresh items.

7

Publication & Archiving

Pushes the page blocks to Notion, appends selections to the master CSV database, saves unused candidates to the bench_v11.json cache for the next run, and dumps audit files.
